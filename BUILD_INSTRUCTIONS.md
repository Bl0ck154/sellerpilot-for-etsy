# Build Instructions

## Source of truth

Edit files under `src/`. The canonical browser manifest is:

```text
src/manifest.json
```

Do not maintain separate Chrome/Firefox source manifests.

## Prerequisites

The included build scripts target Windows and use:

- `cmd.exe`
- PowerShell
- built-in `xcopy`
- PowerShell `Compress-Archive`

No package installation is required by the build script itself.

## Build both browsers

From the repository root:

```cmd
build.bat
```

Generated output:

```text
dist/
  chrome/
  firefox/
  etsy-ai-assistant-firefox-<version>.xpi
```

`dist/` is generated and ignored by Git. Do not edit generated files as source.

## Chromium development

You can load `src/` directly during development:

1. Open `chrome://extensions/` or `edge://extensions/`.
2. Enable Developer mode.
3. Select **Load unpacked**.
4. Choose the repository's `src` directory.

Or run `build.bat` and load `dist/chrome/` to test the packaged source layout.

## Firefox development

Run `build.bat`, then:

1. Open `about:debugging#/runtime/this-firefox`.
2. Choose **Load Temporary Add-on**.
3. Select `dist/firefox/manifest.json`.

The build script runs `build-firefox-manifest.ps1`, which derives Firefox settings from `src/manifest.json`.

## Version changes

When preparing a release, keep the extension version synchronized between:

- `src/manifest.json`
- `build.bat`

Then rebuild and confirm the generated manifests contain the expected version.

## Before committing

- Do not commit `dist/`, ZIP/XPI artifacts, logs, browser profiles, HAR files, local databases, credentials, or private Etsy/customer data.
- Keep fixtures synthetic.
- Validate edited JSON files.
- Run the relevant tests for changed behavior.
- Build both browser variants when changing the manifest, build scripts, or browser-specific behavior.

## Troubleshooting

### Chromium build does not load

Check `dist/chrome/manifest.json` and the extension error panel in `chrome://extensions/` or `edge://extensions/`.

### Firefox build does not load

Check `dist/firefox/manifest.json` and the Browser Console. Firefox-specific manifest differences are generated by `build-firefox-manifest.ps1`.

### Changes are missing

Re-run `build.bat`, reload the extension, and refresh the Etsy page.
